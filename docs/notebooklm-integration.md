# NotebookLM workflow

Serapis does not automate NotebookLM. When an academic record and cached preparation exist, the workspace workflow can create a Markdown study source. Upload that file manually using NotebookLM's supported interface, and replace it when the local export changes.

```sh
./serapis workspace SYN101 --week 1
```

NotebookLM conversations and generated material are study aids. They are not imported into Serapis as evidence. Check claims against the cited source IDs and page references. Product features and supported source formats can change; consult current NotebookLM help for service details.
